OSS on services we host.
Charge for the service, not the code.

I love building open source software and using it. In the age of AI, more and more software will be written by people with AI — mostly running on managed backends that someone else makes money from. Only the interface changes. We can do it differently: open source on top of services we host ourselves — ask money for the service, not the code. More about me on geert.md →
