Monetize OSS

by Geert Theys

Open source software in the age of AI — and how to actually make money from it.

Why I'm doing this

I love building open source software and using it. In the age of AI, more and more software will be written by people with AI — and most of it will run on managed backends that someone else makes money from. Only the interface changes, and how you use those backends.

This is where I think we can work differently: open source software that runs on top of services we host ourselves — and ask money for the service, not the code.
